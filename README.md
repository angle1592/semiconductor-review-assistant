# 拾要

> 把散落的资料，整理成可复习、可追溯、由你决定轻重的内容。

拾要是一款本地优先的总复习工作台。你可以导入 PDF、Word、PowerPoint、TXT 或 Markdown，亲自说明“什么重要”，也可以把这套标准交给自己接入的第三方 AI，生成重点、提纲、记忆卡和练习题，再用明确的自评记录掌握情况。

## 已交付能力

- 按复习项目管理资料、重要性提示词和正式重点；
- 导入 `.pdf`、`.docx`、`.pptx`、`.txt`、`.md`，并在 Windows 上降级处理 `.doc`、`.ppt`；
- 接入 OpenAI 兼容或 Anthropic 协议的第三方 API；
- 校验地址与密钥、获取模型、手动添加模型，并探测文本、结构化输出和视觉能力；
- 按所选内容或全部资料进行后台分析，支持持久化进度、失败重试和精确缓存；
- 人工编辑、确认或拒绝候选重点，所有内容保留来源块；
- 保留资料中的原题，生成提纲、记忆卡、新题、变式题和错因题；
- 按需复习并记录“学习中、较熟悉、已掌握”等显式判断，不自动安排日程；
- 导出和恢复正式数据备份，分别查看或清理解析缓存与 AI 结果缓存；
- 导出不含密钥、资料正文、提示词和生成正文的脱敏诊断包；
- 以普通用户安装运行 Windows 应用，API 与后台任务进程均可安全退出。

## Windows 安装

发布文件为：

- `Shiyao-0.1.0-beta-Setup.exe`
- `Shiyao-0.1.0-beta-Setup.exe.sha256`
- `Shiyao-Guide-zh-CN.pdf`

安装器使用当前用户目录，不申请管理员权限。首次启动会在本机动态端口运行，只监听 `127.0.0.1`，然后打开默认浏览器。详细步骤见 [用户指南](docs/user-guide.md)。

本测试版尚未进行代码签名。若 Windows SmartScreen 提示未知发布者，请先确认下载来源并核对 SHA-256，再决定是否运行。

## 支持格式与限制

| 格式 | 处理方式 | 可能的降级 |
| --- | --- | --- |
| PDF | 提取文本、页码并生成页面预览 | 加密或损坏文件需移除密码或重新导出 |
| DOCX | 提取标题、段落、表格和内嵌图片 | 复杂版式可能只保留结构化文本 |
| PPTX | 提取幻灯片文本与讲者备注 | 没有 PowerPoint 时不生成幻灯片预览，但文本仍可用 |
| TXT / Markdown | 按文本结构生成稳定内容块 | 不生成页面图像 |
| DOC / PPT | 调用本机 Word / PowerPoint 转换 | 没有对应 Office 应用时要求另存为现代格式 |

单文件上限默认 100 MB。扫描型 PDF 没有 OCR 文本时，可使用具备视觉能力的模型分析页面图像。

## 第三方 AI 接入

拾要不提供内置云账号或共享密钥。首次打开连接向导，或在“设置”中新建服务：

1. 选择 OpenAI 兼容或 Anthropic 协议；
2. 填写 HTTPS API 地址、服务名称和自己的 API Key；
3. 获取模型列表；若服务商未提供列表接口，可手动输入模型 ID；
4. 选择模型并校验文本、结构化输出和视觉能力；
5. 三项必需能力通过后启用服务，可设为默认服务。

校验只发送内置短文本、固定 JSON Schema 和 1×1 测试图片，不会发送你的项目名称、提示词或资料。密钥保存到 Windows 凭据管理器，不写入数据库、日志、备份或诊断包，也不会在界面中回显。

## 资料到复习的工作流

1. 新建复习项目，并填写你判断重要内容的标准；
2. 导入资料，查看解析状态、提醒、内容块和页面预览；
3. 选择内容块或全部资料，确认范围后提交后台分析；
4. 回看来源，编辑并确认候选重点；
5. 选择已确认重点和可选原题，生成需要的复习内容；
6. 主动显示答案、记录正确性或自评掌握程度；
7. 在“掌握情况”中按类型和程度筛选，不进行日历预测。

第三方 AI 的输出永远先进入待确认或生成内容，不会替代你的最终判断。原题答案和 AI 生成答案分开保存。

## 缓存语义

拾要使用两类本机缓存：

- `Runtime/parse-cache`：按文件内容哈希和解析器版本复用解析结果；
- `Runtime/ai-cache`：按协议、服务配置代次、模型、资料范围、提示词、Schema、参数和管线版本进行严格精确匹配。

修改模型、提示词、范围、服务地址或密钥代次都会导致 AI 缓存失配。没有语义缓存，不会拿“相似答案”替代本次请求。模型列表缓存 15 分钟，可手动刷新。

清理缓存不会删除原文件、重点、原题、生成内容、掌握记录或备份；下一次操作可能重新解析或消耗第三方额度。设置页要求以当前字节数确认，避免误操作。

## 后台任务与恢复

分析和内容生成由独立 worker 执行。关闭或刷新页面不会取消任务；任务进度、批次、重试时间和缓存命中都保存在本机数据库。worker 异常退出后，新 worker 会接管租约到期的任务，已成功批次不会重复调用模型。

源码开发时 API 与 worker 分别启动：

```powershell
cd backend
.\.venv\Scripts\python.exe -m app.runner
.\.venv\Scripts\python.exe -m app.jobs.worker
```

也可以从仓库根目录运行 `start.ps1`，用 `stop.ps1` 安全停止两个进程。

## 数据、备份与隐私

打包版数据目录：

```text
%LOCALAPPDATA%\Shiyao\
├── Data\        # shiyao.db、原始资料和预览资产
├── Backups\     # 用户导出的备份
├── Logs\        # 已脱敏运行日志
└── Runtime\     # 缓存、实例元数据和任务停止信号
```

备份包含正式数据库、原文件和恢复所需预览资产，不包含密钥、缓存、日志、现有备份或 worker 租约。恢复前会校验格式、产品标识、重复路径、路径穿越和每个文件的 SHA-256，并采用失败回滚。

只有当你主动提交分析或生成任务时，所选内容才会发送给当时选择的第三方服务。项目其余数据不进行云同步。

完全删除拾要数据：先安全退出应用，在 Windows“已安装的应用”中卸载；卸载完成时明确选择同时删除用户数据。也可以在确认不再需要备份后手动删除 `%LOCALAPPDATA%\Shiyao`。

## 故障排查

- **无法获取模型**：检查 API 地址是否为服务商要求的基础地址；可用手动模型 ID 继续。
- **401 / 403**：替换或重新保存 API Key，确认账户有权访问该模型。
- **404**：核对基础地址中的版本路径和模型 ID。
- **429**：等待服务商限流窗口恢复，或减少分析范围后重试。
- **模型能力不通过**：换用支持结构化输出和视觉输入的模型，再运行校验。
- **Office 预览不可用**：安装对应 Office 应用，或把文件另存为 PDF、DOCX、PPTX。
- **任务停在等待中**：安全退出并重新打开应用；持久化任务会继续。
- **需要反馈问题**：从设置页导出诊断包，附上发生时间和操作步骤；不要另行上传原资料或密钥。

## 开发与验证

需要 Python 3.12+、Node.js 和 npm：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
cd ..\frontend
npm ci
npm run build
cd ..
.\start.ps1
```

完整验证：

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m ruff check app tests
cd ..\frontend
npm test
npm run lint
npm run build
npm run test:e2e
```

测试使用本机模拟服务，不需要真实 API Key。
