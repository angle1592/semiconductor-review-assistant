# 拾要

拾要是一款本地优先的总复习工作台。目标是导入 PPT、Word 等复习资料，由使用者直接说明“什么最重要”，或把这套标准交给第三方 AI，用它整理重点并支持后续复习。

## 当前阶段

当前已完成 Phase 2，交付以下真实能力：

- 全新的拾要产品身份、本机数据目录与独立数据库；
- 复习项目的新建、查看、编辑和删除；
- 项目内“概览、资料、重点、复习、掌握情况”五步工作区；
- 多个 OpenAI 兼容或 Anthropic 第三方 AI 服务；
- API 地址规范化、模型列表获取、手动模型回退与默认服务选择；
- 文本、结构化输出、视觉和提示词缓存能力徽标；
- 明确的鉴权、权限、地址、限流和能力校验错误提示。

以下能力将在后续阶段接入：

- PPT、PPTX、DOC、DOCX 等资料导入和文本/图片提取；
- 由用户规则或 AI 识别重点，以及结果缓存和重新分析；
- 重点确认、题目生成、正式复习和掌握情况统计；
- 新身份下的 Windows 安装包、快捷方式和发布流程。

## 第三方 AI 设置

首次打开 `/setup`，或在“设置”中选择“新增服务”，按六步完成接入：

1. 选择 OpenAI 兼容或 Anthropic 协议；
2. 填写 API 地址、服务名称和 API Key；
3. 获取服务商公开的模型列表；
4. 选择要使用的模型；如果服务商没有模型列表接口，可手动填写模型 ID；
5. 运行文本、结构化输出和视觉能力校验；
6. 三项必需能力均通过后启用服务，并按需设为默认服务。

地址输入区会预览实际使用的模型列表与推理端点。能力徽标中的“缓存”表示服务商是否支持或报告提示词缓存；缓存不支持不会阻止服务启用。模型列表在本机缓存 15 分钟，“刷新模型”会强制重新获取。

能力校验只发送拾要内置的固定短文本、固定 JSON Schema 和一张 1×1 测试图片，不会发送项目名称、用户提示词或任何复习资料。

## 开发运行

后端需要 Python 3.12，前端需要 Node.js 与 npm。

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
cd ..\frontend
npm ci
npm run build
cd ..
.\start.ps1
```

本机服务默认打开 `http://127.0.0.1:8000`。停止服务：

```powershell
.\stop.ps1
```

## 验证

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m ruff check app tests
cd ..\frontend
npm test
npm run lint
npm run build
npm run test:e2e
```

测试使用确定性的本地模拟服务，不需要也不会消耗真实 API Key。

## 数据与隐私边界

- 项目、服务配置和模型校验结果以 SQLite 保存在本机，不包含账户或云同步。
- 每个服务的 API Key 使用独立的 Windows 凭据项保存，不写入数据库、日志、诊断包或备份，也不会在页面回显。
- 当前阶段不会上传学习资料，因为资料导入与分析尚未实现。
- 后续只有在用户明确发起分析时，所选资料内容才会发送给当时选择的第三方 AI 服务和模型。
