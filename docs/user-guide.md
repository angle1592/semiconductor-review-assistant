# 拾要

## Windows 测试版安装与使用说明

版本：0.1.0-beta

系统：Windows 10 / 11 64 位

发布者：angle1592

拾要帮助你把 PDF、Word、PowerPoint 和文本资料整理成可追溯的重点与复习内容。重要性标准由你填写；第三方 AI 只负责按这套标准协助提取和生成，最终确认权始终在你。

## 1. 安装前校验

把安装程序和摘要文件放在同一目录，在 PowerShell 中运行：

```powershell
Get-FileHash '.\Shiyao-0.1.0-beta-Setup.exe' -Algorithm SHA256
Get-Content '.\Shiyao-0.1.0-beta-Setup.exe.sha256'
```

两处 64 位十六进制摘要必须一致。摘要不同就不要运行安装器。本测试版尚未代码签名，SmartScreen 可能提示未知发布者；只在确认来源和摘要后继续。

## 2. 安装、启动与退出

1. 双击 `Shiyao-0.1.0-beta-Setup.exe`；
2. 保持默认的当前用户安装位置；
3. 从桌面或开始菜单打开“拾要”；
4. 程序会启动隐藏的本机 API 与后台任务进程，并打开默认浏览器。

安装与运行不需要管理员权限。服务只监听 `127.0.0.1` 的动态端口，不向局域网开放。再次点击快捷方式会复用现有实例。

关闭浏览器不会停止任务。需要完整退出时，在设置页选择安全退出；安装升级和卸载也会先停止两个本机进程。

## 3. 第三方 API 配置

首次打开按连接向导操作：

1. 选择 OpenAI 兼容或 Anthropic；
2. 填写服务名称、HTTPS API 地址和自己的 API Key；
3. 点击获取模型；若没有列表接口，手动输入准确的模型 ID；
4. 选择模型并运行能力校验；
5. 文本、结构化输出和视觉均通过后启用服务。

地址错误、鉴权失败、权限不足、接口不存在、限流和能力不匹配都会显示不同提示与下一步操作。模型列表在本机缓存 15 分钟，可随时强制刷新。

能力校验只发送内置短文本、固定 Schema 和测试图片，不发送你的资料。API Key 保存在 Windows 凭据管理器，不写入数据库、备份、日志和诊断包。

## 4. 导入资料

支持 PDF、DOCX、PPTX、TXT 和 Markdown，单文件默认上限 100 MB。DOC 和 PPT 需要本机安装 Word 或 PowerPoint 完成转换。

- PDF 会提取文本、页码和页面预览；
- DOCX 会提取标题、段落、表格和图片；
- PPTX 总会提取文字与讲者备注，没有 PowerPoint 时只缺少幻灯片预览；
- TXT 与 Markdown 会生成稳定内容块；
- 加密、损坏或不支持的文件会给出明确错误，不会静默忽略。

“解析完成，但有提醒”表示仍有可用内容。你可以先查看提醒和内容块，再决定是否交给 AI。

## 5. 从重点到复习

1. 新建项目，填写“什么内容最重要”；
2. 导入资料并确认分析范围；
3. 选择服务和模型，提交后台分析；
4. 查看候选重点的证据与来源，编辑后确认或拒绝；
5. 用已确认重点生成提纲、记忆卡、新题；
6. 选择原题生成变式题或错因题；
7. 主动显示答案并记录正确性或掌握程度。

原题与 AI 题目使用不同标识和存储，不会互相覆盖。生成内容记录服务、模型、所选重点、所选原题和缓存状态。

拾要按需开始复习，不自动安排日程、到期任务或连续打卡。

## 6. 缓存与后台恢复

解析缓存按文件哈希和解析器版本命中；AI 结果缓存要求协议、服务配置代次、模型、内容、提示词、Schema 和参数全部一致。修改任一条件都会重新请求，不会使用相似内容替代。

设置页会显示两类缓存的文件数和字节数。清理时必须输入当前字节数确认。清理缓存不会删除资料、重点、题目、复习内容、掌握记录和备份，但下次可能重新解析或调用第三方服务。

任务在独立 worker 中运行。刷新页面或关闭浏览器后任务继续；意外退出后，新进程会接管未完成任务，成功批次不会重复执行。

## 7. 备份、诊断与隐私

本机目录：

```text
%LOCALAPPDATA%\Shiyao\
├── Data\
├── Backups\
├── Logs\
└── Runtime\
```

备份包含正式数据库、原文件和恢复所需预览资产；不包含 API Key、缓存、日志、既有备份和运行租约。恢复前会验证格式、产品标识、路径安全和每个文件摘要，失败时回滚。

诊断包只包含版本、目录可写性、脱敏服务信息、模型能力状态、任务计数、缓存统计、公开错误码和脱敏日志。它不包含密钥、请求头、资料正文、证据、题目答案、提示词和生成正文。

只有你主动提交的范围会发送给所选第三方服务。拾要没有账户系统或云同步。

## 8. 更新、卸载与彻底删除

运行新版安装器会先安全停止旧实例，再覆盖程序文件；用户数据继续保留。卸载默认也保留数据，便于重装。

若要彻底删除：

1. 先导出需要保留的备份；
2. 在设置页安全退出；
3. 从 Windows“已安装的应用”卸载“拾要”；
4. 卸载完成时明确选择同时永久删除用户数据。

之后可检查 `%LOCALAPPDATA%\Shiyao` 是否已不存在。不要删除名称相似但不属于拾要的目录。

## 9. 常见错误

### 获取模型失败

核对服务商要求的基础地址和版本路径。若服务商没有模型列表接口，使用手动模型 ID。

### 鉴权或权限错误

重新保存 API Key，确认账户余额、项目权限和模型访问权。密钥替换后要重新校验能力。

### 视觉能力失败

换用明确支持图片输入的模型。扫描型 PDF 没有文本层时尤其需要视觉能力。

### Office 文件只有文字没有预览

安装对应的 Microsoft Office 应用，或另存为 PDF、DOCX、PPTX 后重新导入。

### 任务长时间等待

安全退出并重新打开拾要。任务状态保存在数据库中，会由新的 worker 继续。若仍失败，从设置页导出诊断包。

### 如何反馈

提供问题发生时间、操作步骤、应用版本和脱敏诊断包。不要上传原资料、API Key 或含私人内容的截图。
