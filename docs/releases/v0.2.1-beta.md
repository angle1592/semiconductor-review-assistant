# 拾要 v0.2.1-beta

本版本修复 OpenAI 兼容服务在严格结构化输出能力校验中的兼容问题。

## 修复

- 递归补全 JSON Schema 对象的 `additionalProperties: false` 声明；
- 修复部分第三方网关中文本和视觉校验通过、结构化输出却被误判失败的问题；
- 保留既有的鉴权、限流、网络和响应格式错误分类；
- 增加嵌套对象 Schema 的回归测试。

## 验收

- 后端全量测试和 Ruff 检查通过；
- 使用真实 OpenAI 兼容第三方服务连续两次验证文本、结构化输出和视觉能力均通过；
- 提示词缓存继续按不支持处理，不影响模型启用。

安装器仍为当前用户级安装，不请求管理员权限。正式使用前请使用同名 SHA-256 文件校验安装器。
