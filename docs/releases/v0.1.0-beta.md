# 拾要 v0.1.0-beta

首个“拾要”Windows 测试版：面向跨学科总复习，把本地资料整理为可追溯的重点、原题、提纲、记忆卡和练习题。

## 主要能力

- 导入 PDF、Word、PowerPoint、TXT 和 Markdown；
- 自定义“什么重要”，或由所接入的第三方 AI 按提示词识别；
- 支持 OpenAI 兼容与 Anthropic 协议、模型发现、手动模型和能力校验；
- 后台分析、持久化重试、精确缓存、候选重点人工确认；
- 生成提纲、记忆卡、新题、变式题和错因题，并保留来源；
- 按需记录正确性和掌握程度，不自动安排日程；
- 本地 SQLite、Windows 凭据存储、正式数据备份和脱敏诊断；
- 动态本地端口、单实例启动、独立 worker、安全退出和普通用户安装；
- 覆盖升级与卸载默认保留个人数据，可明确选择彻底删除。

## 下载与校验

下载安装器、同名 SHA-256 文件和中文 PDF 指南。运行前按指南核对摘要。本测试版尚未代码签名，SmartScreen 可能显示未知发布者。

## 系统要求

- Windows 10 或 Windows 11 64 位；
- 旧版 DOC/PPT 转换及 Office 页面预览需要对应的 Microsoft Office 应用；
- AI 功能需要使用者自己的第三方 API 地址、密钥和兼容模型。

测试版暂不包含自动更新、账户系统、云同步、OCR 或代码签名。建议定期导出备份；反馈问题时附脱敏诊断包，不要上传原资料或密钥。
