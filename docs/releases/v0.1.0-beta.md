# 半导体复习台 v0.1.0-beta

首个公开 Windows 测试版，适合半导体培训课后进行 10～15 分钟主动复习。

## 主要能力

- 导入 PDF、PPT/PPTX 课件并按页选择当天内容；
- 使用 OpenAI 兼容 API 或本机 Codex 生成带来源页的短复习题；
- 结合 AI 评分与“确定、模糊、不会”自评安排间隔复习；
- 课程和课件可连同关联题目、答案、复习历史完整删除；
- 本地 SQLite、Windows 凭据存储、备份恢复与脱敏诊断；
- 动态本地端口、单实例启动、快捷方式打开和安全退出；
- 当前用户安装，覆盖升级保留个人数据，卸载默认保留个人数据。

## 下载

下载安装程序、同名 SHA256 文件和安装说明 PDF。运行前请按照 PDF 中的步骤校验 SHA256。

本测试版尚未购买代码签名证书，Windows SmartScreen 可能显示警告。确认下载来源和摘要一致后，选择“更多信息”→“仍要运行”。

## 系统要求

- Windows 10 或 Windows 11 64 位；
- PPT/PPTX 导入需要本机 Microsoft PowerPoint，否则请先转为 PDF；
- AI 功能需要使用者自己的 OpenAI 兼容 API，或本机已登录的 Codex。

这是 prerelease。使用前建议定期从设置页导出备份；提交问题时请附脱敏诊断包，不要上传原课件或 API Key。
