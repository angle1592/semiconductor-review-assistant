# 拾要 v0.2.2-beta

本版本修复超大 PPTX 资料只显示前 100 个内容块、分析批次数异常膨胀以及第三方结构化输出失败的问题，并增强长任务恢复能力。

## 修复

- 资料预览自动分页加载全部内容块，不再停在接口默认的前 100 条；
- PPTX 解析增加表格文字，并为纯图片页保留可分析的页面占位；
- 同一页的多个文字块只计作一张预览图，277 页实测由 103 批降为 38 批；
- 严格 JSON Schema 递归补全对象的 `required` 与 `additionalProperties: false`；
- 第三方推理超时从 60 秒提高到 180 秒，分析任务最大尝试次数从 3 次提高到 5 次；
- 任务部分完成时立即生成已成功批次的候选重点和原题，重试仍只处理失败批次。
- Windows 启停脚本移除可能无限阻塞的 WMI 进程查询，并继续校验应用健康标识、端口、PID 和解释器路径。

## 验收

- 使用 277 页、约 61 MB 的真实 PPTX 完成导入、277 页预览、758 个内容块加载和 38 批 AI 分析；
- 首次完整分析成功生成 545 个候选重点和 44 道原题；
- 相同资料再次分析时 38 批全部命中本机缓存，第三方新增调用为 0；
- 后端 145 项测试、Ruff、前端 21 项测试、ESLint 和生产构建全部通过。

安装器仍为当前用户级安装，不请求管理员权限。正式使用前请使用同名 SHA-256 文件校验安装器。
