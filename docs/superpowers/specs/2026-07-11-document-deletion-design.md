# 课件删除设计

## 目标

让用户在课程页永久删除误导入或不合适的 PDF、PPT、PPTX，并同步清理本机文件与页面索引。

## 删除语义

- 删除课件原文件、PowerPoint 转换出的 PDF、所有页面预览图、`Document` 与所属 `Page` 记录。
- 已生成的课次、题目、作答和间隔复习记录继续保留，避免删除课件时误删学习成果。
- 历史题目引用已删除页面时，现有来源解析逻辑将其显示为不可用来源。
- 删除是永久操作，前端必须显示包含文件名和影响范围的确认提示。

## 架构

- 后端增加 `DELETE /api/documents/{document_id}`，路由负责查找记录和提交事务，内容服务负责限制并清理三个已知课件目录。
- 前端 typed fetch 客户端增加 `deleteDocument()`；课程页使用 React Query mutation 调用接口并刷新课件列表。
- 不增加软删除、回收站、批量删除或级联清理学习历史。

## 错误处理

- 文件不存在返回现有的 `NOT_FOUND` 404。
- 文件系统清理失败时不删除数据库记录，由全局错误处理返回失败；用户可以重试。
- 删除进行中禁用对应按钮；失败时在课件区域显示明确提示。

## 验收

- 删除按钮在每份课件卡片上可见且需要确认。
- 成功后课件立即从列表消失，GET 接口返回 404。
- 原文件、转换文件、预览目录和页面数据库记录均不存在。
- 已有课次和题目仍保留。
