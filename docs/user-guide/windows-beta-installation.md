# 半导体复习台

## Windows 测试版安装与使用说明

版本：0.1.0-beta  
系统：Windows 10 / 11 64 位  
发布者：angle1592

半导体复习台是一个本地优先的课后复习助手。你可以导入培训课件，选择当天页面，用 10～15 分钟完成主动回忆、纠错、自评和间隔复习。

## 1. 下载与校验

请从 GitHub Release 下载以下三个文件：

- `SemiconductorReview-0.1.0-beta-Setup.exe`：安装程序；
- `SemiconductorReview-0.1.0-beta-Setup.exe.sha256`：安装程序校验值；
- `SemiconductorReview-Guide-zh-CN.pdf`：本说明。

把安装程序和 SHA256 文件放在同一目录，打开 PowerShell，执行：

```powershell
Get-FileHash '.\SemiconductorReview-0.1.0-beta-Setup.exe' -Algorithm SHA256
Get-Content '.\SemiconductorReview-0.1.0-beta-Setup.exe.sha256'
```

两处显示的 64 位十六进制摘要必须完全相同。不同就不要运行安装程序，请重新下载。

## 2. 安装

1. 双击 `SemiconductorReview-0.1.0-beta-Setup.exe`；
2. 保持默认安装位置并完成安装；
3. 从桌面或开始菜单打开“半导体复习台”；
4. 程序会启动本机服务并在默认浏览器中打开页面，不需要命令行。

本测试版尚未购买代码签名证书。Windows SmartScreen 可能显示“Windows 已保护你的电脑”。确认文件来自本项目 GitHub Release 且 SHA256 校验一致后，可选择“更多信息”→“仍要运行”。

程序仅监听 `127.0.0.1` 的动态端口，不会向局域网或公网开放。关闭浏览器不会关闭本机服务；再次点击快捷方式会复用已有服务并重新打开页面。

## 3. 首次 AI 配置

第一次打开会进入连接向导。每位使用者应配置自己的服务，不要共用或转发他人的 API Key。

### OpenAI 兼容 API（推荐起步）

填写服务地址、模型名称和 API Key。若需要直接理解课件页面图片，请选择支持视觉输入的模型，并保留“允许处理所选课件页面图片”。保存后可在“设置”页测试连接与能力。

API Key 写入 Windows 凭据存储，不进入 SQLite、备份或诊断包。服务连接失败时，程序不会把课件自动转发给其他后端。

### Codex（高级选项）

Codex 会尝试使用本机已有的 Codex 登录，不复制凭据。只有已经在这台电脑完成 Codex 登录的用户才应选择它；能力测试未通过时，请切回 OpenAI 兼容 API。

## 4. 日常使用

1. 在“课程”中新建课程；
2. 进入课程并导入 PDF、PPT 或 PPTX；
3. 选择当天课件页面，最多补充“老师强调、实践内容、个人疑问”；
4. 生成并完成 10～15 分钟主动回忆；
5. 根据“确定、模糊、不会”自评，系统自动安排当天、2 天、7 天、21 天和 60 天复习。

每道题都保留来源页。坏题可以跳过、修改或标记，不计入掌握度。

PPT/PPTX 依赖本机 Microsoft PowerPoint 转换成 PDF。未安装 PowerPoint 时，请先在其他软件中另存为 PDF 再导入。第一版不提供 OCR；扫描型 PDF 需要支持视觉输入的模型。

## 5. 数据、备份与诊断

正式学习数据默认保存在：

```text
%LOCALAPPDATA%\SemiconductorReview\
├── Data\
├── Backups\
├── Logs\
└── Runtime\
```

在“设置”页可以：

- 导出完整 ZIP 备份；
- 从备份恢复；
- 打开数据目录和日志目录；
- 导出脱敏诊断包；
- 安全退出本地服务。

备份不包含 API Key。诊断包不包含课件、数据库、答案、复习历史或凭据。

## 6. 更新与卸载

更新时直接运行新版安装程序，保持默认路径覆盖安装即可。程序会先安全停止旧服务，程序文件被替换，个人数据继续保留。数据库结构升级前会自动建立安全备份，并保留最近 5 份。

从 Windows“已安装的应用”卸载时，默认保留个人数据，方便以后重装。卸载末尾只有在明确选择“是”时才会永久删除课程、课件、答案、复习历史、备份和日志。

## 7. 常见问题

### 快捷方式打开后没有页面

再次点击快捷方式。若仍无页面，在“任务管理器”结束 `SemiconductorReview.exe` 后重试；也可以重启 Windows。

### AI 连接失败

依次检查服务地址是否包含正确的 `/v1` 路径、模型名称是否由服务商提供、API Key 是否有效、模型是否支持图片。失败不会自动切换到另一服务。

### 图片型课件无法生成题目

在设置页运行能力测试。如果当前模型没有视觉能力，请切换视觉模型，或导入 NotebookLM 生成的 Markdown/TXT 学习指南。

### 反馈问题

在“设置”→“桌面维护”中导出诊断包，连同问题发生时间和操作步骤提交到 GitHub Issues。不要上传原始课件、API Key 或包含个人信息的截图。
